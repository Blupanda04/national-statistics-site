IndoStats adalah situs statistik nasional Indonesia: penduduk, ekonomi, harga, tenaga kerja, dan kesejahteraan — setiap angka membawa sumber dan tahunnya. Halaman beranda menampilkan enam indikator utama, grafik penduduk 2010–2024, dan pertumbuhan PDB; halaman Penduduk memuat tabel 10 provinsi terpadat yang bisa diurutkan; halaman Ekonomi memuat PDB, PDB per kapita, pertumbuhan, dan pangsa sektor; halaman Harga memuat inflasi; halaman Tenaga Kerja memuat pengangguran, kemiskinan, dan IPM; halaman Metodologi memuat semua sumber dan cara mengutip. Semua grafik digambar sebagai SVG tanpa pustaka, dan situs bekerja sepenuhnya tanpa jaringan.

## Run it

```sh
node serve.ts   # http://localhost:8083
```
